# Creator Agents

## Regle de routage

Quand l'utilisateur demande une **feature**, prends comme reference principale:

- [angular-feature-creator.md](ai/agents/creator/angular-feature-creator.md)

Quand l'utilisateur demande un **component** ou un **composant**, prends comme reference principale:

- [angular-component-creator.md](ai/agents/creator/angular-component-creator.md)

## Interpretation attendue

- Une demande de type `create feature ...`, `cree une feature ...` ou toute demande equivalente de nouvelle feature Angular doit suivre `angular-feature-creator.md`.
- Une demande de type `create component ...`, `cree un composant ...` ou toute demande equivalente de nouveau composant Angular doit suivre `angular-component-creator.md`.
- Si la demande est ambigue entre feature et component, demander une clarification avant de generer ou modifier des fichiers.
